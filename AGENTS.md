Прочитай его целиком перед любой правкой: там архитектура, флаги,

ревью, ни CI. Дублировать контекст снова не надо: он опять разойдётся.

## Минимум, который нужно знать до правок

- Рабочая копия — `V:\md-converters`, ветка `main`, репозиторий
  **публичный**. Git-операции: `git -C "V:\md-converters" ...`.
- Язык проекта — русский: интерфейс, README, комментарии, коммиты.
- `convert_to_md.py` — всё ядро конвертации (CLI `tomd` / `pdf2md` /
  `html2md`). `gui_server.py` + `gui_static/` — Web-GUI, слой ПОВЕРХ
  ядра, опциональная зависимость `[gui]`.
- Длина строк в `.py` — **≤ 79 символов** (ruff E501 в CI).
- Проверки перед коммитом (тот же набор, что гоняет CI):
  `uv lock --check` ; `uv run --frozen --extra gui ruff check
  convert_to_md.py gui_server.py tests tools` ; `uv run --frozen
  --extra gui pytest -q`.
- Контракт фронтенда GUI (id элементов, поля SSE-событий) —
  `docs/gui-contract.md`; менять разметку, не сверившись с ним, нельзя.
- Коммиты заканчиваются строкой соавтора с ИМЕНЕМ ТЕКУЩЕЙ МОДЕЛИ:
  `Co-Authored-By: Claude <модель> <noreply@anthropic.com>`.

## Чего НЕ делать (проверено и отклонено — не «чинить» заново)

Разбор — в CLAUDE.md, пункты 13 и 17 истории:

- НЕ снимать `_CONVERT_LOCK` в `gui_server.py` и не менять контракт
  `convert_file() -> str` ради «параллелизма»: лок держит
  ПРОЦЕСС-ГЛОБАЛЬНЫЙ `redirect_stdout` и общий `opts["planned"]`, а
  возвращаемое значение завязано на `run()` и десяток тестов.
- НЕ удалять ключ `max_url_mb` как «мёртвый»: его читает
  `_build_opts` при расчёте `max_url_bytes` — получите `KeyError`.
- НЕ заменять `except Exception` вокруг сторонних парсеров: это
  фолбэк, чтобы один битый файл не ронял пакетный прогон.
- НЕ «упрощать» префиксное сравнение `_source_id_matches`: это
  совместимость со старым 16-символьным хэшем.
- НЕ переписывать кириллические регекспы детектора прозы на латиницу.

## Как проверять свои правки

Тест обязан ловить именно тот дефект, ради которого написан: откати
фикс и убедись, что тест **краснеет**. Приёмом за одну итерацию работы
над GUI пойманы два собственных теста, которые проходили и со
сломанным кодом.
